# Lesson artwork credits

Explainer Studio uses original vector diagrams and artwork from a folder supplied by its owner. A lesson may use a subset of these collections. Each downloadable project identifies the selected imported artwork in `assetManifest`, with source IDs, SHA-256 hashes, attribution and supplied license terms. The adjacent `manifest.json` lists the complete imported catalog.

- OpenMoji: 4,493 supplied SVGs. Graphics by OpenMoji and the contributors named per entry, under Creative Commons Attribution-ShareAlike 4.0: https://creativecommons.org/licenses/by-sa/4.0/. Project: https://openmoji.org/. The imported SVG geometry and colors are preserved; video animation reveals and moves the whole image.
- Generated sketch illustrations: 194 user-supplied SVGs. The supplied catalog does not specify license terms; no application license is assigned to these images.
- Iconify illustrations: 131 user-supplied SVGs. Collection names are preserved per entry. The supplied folder does not include license terms; no application license is assigned to these images.
- Legacy pinned OpenMoji artwork and animation adaptations have separate notices in `/openmoji/NOTICE.md` and `/openmoji/manifest.json`.
- Native vector diagrams are original Explainer Studio illustrations. Kalam lettering is under the SIL Open Font License.

Credits appear outside the video canvas. Artwork metadata describes the source image, not evidence for a scientific claim.
